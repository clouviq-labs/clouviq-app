# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

Please do not open a public issue.

Report it privately: open the **Security and quality** tab
and click **Report a vulnerability**.

- We reply within 3 business days.
- We aim to ship a fix within 30 days.
- We credit you in the published advisory.
